# Airplanes Project (Курсовая работа)

## Описание проекта

Данный проект представляет собой интеграцию с внешними API для сбора информации о самолётах в воздушном пространстве выбранных стран.

## Реализованный функционал

### Работа с API

#### Класс `BaseAPI` (абстрактный)
- Базовый класс для работы с API внешних сервисов
- Абстрактные методы:
  - `get_country_coordinates(country)` — получение координат страны
  - `get_aeroplanes(country)` — получение данных о самолётах

#### Класс `AeroplanesAPI`
- Наследник `BaseAPI`
- Работает с API:
  - **nominatim.openstreetmap.org** — координаты стран
  - **opensky-network.org** — данные о самолётах

### Класс `Aeroplane` (Самолёт)

Хранит информацию о самолёте:
- `callsign` (str) — позывной
- `origin_country` (str) — страна регистрации
- `velocity` (float) — скорость полёта (м/с)
- `baro_altitude` (float) — высота полёта (м)
- `icao24` (str) — уникальный идентификатор
- `longitude` (float) — долгота
- `latitude` (float) — широта
- `on_ground` (bool) — на земле ли самолёт

**Методы:**
- `__init__` — инициализация с валидацией данных
- `__repr__` — строковое представление
- `__eq__`, `__lt__`, `__gt__` — сравнение по скорости и высоте
- `cast_to_object_list` — класс-метод для преобразования списка данных в список объектов

### Работа с файлами

#### Класс `BaseFileSaver` (абстрактный)
- Базовый класс для работы с файлами
- Абстрактные методы:
  - `add_aeroplane(aeroplane)` — добавление самолёта
  - `get_aeroplanes(criteria)` — получение по критериям
  - `delete_aeroplane(aeroplane)` — удаление

#### Класс `JSONSaver`
- Наследник `BaseFileSaver`
- Сохраняет данные в JSON-файл
- Поддерживает добавление, получение по критериям и удаление

### Функции фильтрации (`main.py`)

- `get_top_aeroplanes(aeroplanes, top_n)` — топ N по высоте (DESC)
- `filter_aeroplanes_by_country(aeroplanes, countries)` — фильтр по стране регистрации
- `filter_aeroplanes_by_altitude(aeroplanes, altitude_range)` — фильтр по диапазону высоты

### Взаимодействие с пользователем

Функция `user_interaction()`:
1. Запрашивает название страны
2. Получает данные о самолётах
3. Сохраняет их в JSON-файл
4. Выводит топ N по высоте
5. Фильтрует по стране регистрации
6. Фильтрует по диапазону высоты

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   ```

2. Установите зависимости:
   ```bash
   poetry install
   ```

3. Запустите основной файл:
   ```bash
   python main.py
   ```

## Запуск тестов
